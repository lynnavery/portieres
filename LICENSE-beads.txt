portieres~ contains the DSP code of Beads by Mutable Instruments, taken
unmodified from https://github.com/pichenettes/eurorack (commit d8f4739,
directory beads/), together with the stmlib library
(https://github.com/pichenettes/stmlib, in source/stmlib/, see LICENSE-stmlib).
